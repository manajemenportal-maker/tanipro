Live Control: HP Mengendalikan Semua Layar

Mode ini membuat HP admin bisa menggerakkan semua layar viewer yang sedang membuka website. Controller mengirim posisi scroll dan menu aktif ke Firebase Realtime Database, lalu viewer mengikuti otomatis.

1. Setting Firebase Realtime

Isi konfigurasi Firebase di bagian script firebaseConfigLive. Setelah domain online, buka website dari HP sebagai controller dan buka website di laptop/TV sebagai viewer.

Gunakan Firebase Realtime Database. Buat rules sementara untuk uji coba, lalu kunci dengan PIN/admin setelah siap produksi.

2. Pilih Mode

Cara pakai:
1) HP Bapak: klik Aktifkan HP Controller.
2) Layar lain: klik Aktifkan Viewer.
3) Saat HP scroll atau pindah menu, semua viewer ikut bergerak.
